# OmniDropShop 🌐🚀

An all-in-one dropshipping website where shoppers can **buy anything**, and you don't need real inventory or storage. When orders are placed, items are sourced and fulfilled via **AliExpress & Temu**, while an automatic **5% markup** is instantly credited to your **Shop Owner Wallet**.

---

## ✨ Key Features

1. **Infinite Catalog & Universal Search**:
   - Shoppers can search for *any* product in the world.
   - If a product isn't already listed, use the **Global Source & List** search bar to instantly query AliExpress & Temu catalogs, import the item, and list it with an automatic 5% markup.

2. **Zero Inventory / Storage Needed**:
   - You act as the storefront platform. When a customer checks out, the order is logged and routed to supplier fulfillment.

3. **5% Profit Wallet Markup**:
   - Every product price includes a 5% profit margin. Upon checkout, 100% of the cost goes toward supplier fulfillment, and the 5% margin is deposited instantly into your **Shop Owner Wallet**.

4. **Order Tracking & Supplier Fulfillment Dashboard**:
   - Real-time tracking of shopper orders, supplier order IDs (`SUP-...`), and fulfillment statuses (`Processing with Supplier`, `Shipped`, etc.).

---

## 🚀 How to Run the Website

1. Double-click **`run_website.bat`** (or open terminal in `OmniDropShop` and run `python app.py`).
2. Open your web browser at:
   **`http://localhost:5000`**
